# Changelog

All notable changes to `laravel-hybrid-search` will be documented in this file.

## v1.0.9 - 2026-11-03

Release the package with Composer identity under the eloquage vendor namespace. This release contains the package metadata and documentation rename; runtime behavior is unchanged.

## v1.0.8 - 2026-10-23

Documentation and package readiness update for Laravel 12 and 13. See README for supported full-text drivers, setup, query macros, and reciprocal rank fusion.

## v1.0.0 - 2026-10-23

Initial public release. See README for supported full-text drivers, setup, query macros, and reciprocal rank fusion.
